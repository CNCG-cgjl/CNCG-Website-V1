# 目标

把记录成本压到最低。  
当一条笔记需要经过在线平台、复杂表单、额外同步和渲染调试时，记录动作本身就会变重。

## 我希望的流程

- 在 `src/content/notes` 新建一个 Markdown 文件
- 写 frontmatter
- 正文直接开始记录
- 提交仓库并上线

```md
---
title: 一篇新笔记
date: 2025-02-10
tags: Vue, Vite
summary: 用一句话说明这篇笔记写什么。
---
```

## frontmatter 建议最少只保留这些字段

1. `title`
2. `date`
3. `tags`
4. `summary`

字段越少，写起来越顺手。

## 什么内容适合写成笔记

- 某个问题的解决办法
- 开发中的中间结论
- 方案比较后的决定
- 值得以后复用的命令或片段

## 什么内容不必写成笔记

如果已经变成稳定教程、完整指南或长期维护文档，更适合进入知识库。
