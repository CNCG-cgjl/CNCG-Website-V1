# 开头说明

先用一两段话说明这篇笔记解决什么问题，或者记录了什么结论。

## 背景

- 这次遇到的场景是什么
- 为什么值得记下来
- 后面可能在哪些地方复用

## 过程

按你的习惯写步骤、思路、排查过程或方案比较。

```bash
# 可以放命令
pnpm dev
```

```js
// 也可以放代码片段
const message = 'hello note'
console.log(message)
```

## 图片

发布到网站时，把图片放进：

`public/uploads/notes/`

Markdown 里这样引用：

```md
![图片说明](/uploads/notes/example.png)
```

如果原图放在 `F:` 盘素材库里，挑出要发布的图片后，再复制一份到上面的项目目录。

## 结论

最后写这篇笔记真正留下来的结论、注意点或后续待办。

- 结论 1
- 结论 2
- 后续再补什么
